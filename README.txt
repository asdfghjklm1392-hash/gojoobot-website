گو جو بات - سایت معرفی با Python و Flask

فایل‌ها:
- app.py
- requirements.txt
- render.yaml
- templates/index.html
- static/logo.jpg

برای اجرای محلی:
1) در CMD وارد پوشه پروژه شوید.
2) اجرا کنید: pip install -r requirements.txt
3) اجرا کنید: python app.py
4) در مرورگر باز کنید: http://127.0.0.1:5000

نکته:
آمار ۲۷ کاربر فعلاً ثابت است. برای آمار زنده باید دیتابیس یا API ربات بله به پروژه متصل شود.
لینک ربات و لینک مدیر تبلیغات را در templates/index.html بررسی کنید.
